# deep-study 项目 Python 脚本功能与步骤说明（中文）

本文档按脚本逐一说明：
1. 这个脚本是做什么的。
2. 它的关键输入和输出是什么。
3. 代码按执行顺序每一步在做什么，以及每一步的作用。

## 1) `185-195mmnihe.py`

功能定位：对 185-195 mm 区间的数据做局部宽度提取和线性拟合，并输出带公式与 R² 标注的图。

关键输入输出：
1. 输入：某目录下的原始波形 CSV（文件名是数字，映射到位置）。
2. 输出：`linear_fit_final_annotated.png`。

执行步骤与作用：
1. 扫描文件夹并筛选目标位置范围文件。
作用：只保留 185-195 mm，避免全量数据干扰局部线性分析。
2. 用 `estimate_period` 估周期，用互相关在受限范围找相位位移，再做差分与 FFT 主频提取宽度。
作用：得到每个波形段的半波长宽度估计，且相位匹配更稳定。
3. 通过 `(0,0)` 到 `(0,61680)` 标记切出有效段并逐段计算。
作用：避开无效区和标记点，只在有效测量段上算宽度。
4. 对同一文件内多段结果做鲁棒均值。
作用：抑制离群段，得到该文件单一代表宽度。
5. 对全部点做 IQR 清洗后线性拟合 `y=kx+b`，计算 R²，绘图保存。
作用：输出局部标定关系与可视化证据。

## 2) `bad train_1d_cnn.py`

功能定位：早期版本学生网络训练脚本（LightWaveNet 基线）。

关键输入输出：
1. 输入：`dataset_distill.npz`。
2. 输出：`best_model_v2.pth`、`training_curve_v2.png`。

执行步骤与作用：
1. 读取 `X/y`，将 `X` 转为 `[N,2,2048]`，将 `y` 归一化到 `[0,1]`。
作用：统一输入维度与标签尺度，便于网络回归。
2. `random_split` 划分训练/验证集。
作用：快速得到验证集，但会有文件级泄漏风险。
3. 构建 `LightWaveNet`（4 层卷积池化 + MLP 回归头）。
作用：提取 1D 时序特征并回归宽度。
4. 使用 `MSELoss + Adam` 训练，`ReduceLROnPlateau` 调学习率。
作用：基础收敛策略。
5. 每轮评估验证损失并保存最优模型。
作用：防止只保留最后一轮权重。
6. 训练后反归一化计算真实 MAE。
作用：用物理尺度解释模型误差。

## 5) `error_solve.py`

功能定位：对失败/离群文件做二次“智能修复”，并合并回结果表。

关键输入输出：
1. 输入：`failed_report.csv`、`outliers_report.csv`、原始 CSV 目录。
2. 输出：`fixed_results.csv`。

执行步骤与作用：
1. `calculate_width` 复用互相关 + FFT 的宽度算法。
作用：保证修复过程与主算法一致。
2. `process_single_file_smart_filter` 对单文件分段并按段长中位数做筛选。
作用：先剔除畸形段，再算宽度。
3. 对可用段宽度再做“中位数邻域”过滤。
作用：去掉数值异常段。
4. 批量读取待修复文件并逐个重算。
作用：自动恢复可修复样本。
5. 将修复结果覆盖/合并到 `fft_results.csv` 生成 `fixed_results.csv`。
作用：得到更完整更干净的宽度表。

## 6) `finaish_end.py`

功能定位：主流程脚本之一，完成全量鲁棒提取 + 双曲线拟合 + 离群诊断。

关键输入输出：
1. 输入：原始 CSV 目录。
2. 输出：`fft_results_robust.csv`、`failed_report.csv`、`outliers_report.csv`、`final_diagnostic_plot.png`。

执行步骤与作用：
1. `calculate_width_constrained`：平滑去均值，估周期，互相关在 ±0.6T 内找位移，FFT 主峰抛物线插值。
作用：稳定提取宽度，降低周期跳变与频率量化误差。
2. `process_single_file_mlv`：按标记切段后做两级清洗。
作用：第一级按段长容差剔除畸形段，第二级按宽度容差剔除异常值。
3. `process_batch_all`：遍历所有数值文件并映射位置。
作用：得到全量 `Position_mm/FFT_Width/Filename` 结果与失败报告。
4. `fit_hyperbola_diagnostic`：先稳健拟合，再 IQR 去离群，再最终拟合。
作用：得到更可信的标定曲线，并记录离群点。
5. 绘制拟合图与残差图。
作用：可视化检查拟合质量与系统性偏差。
